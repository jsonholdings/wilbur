# Wilbur brand

**Name:** Wilbur. Internal project or directory names never appear in
user-facing text (README
headers, package metadata, CLI banner, `--help`).

**Tagline:** A local coding agent for the terminal — tools, subagents, a
plan it keeps — driven entirely by models on your own GPU.

A factual comparison to Claude Code (same shape: tools, subagents, a kept
plan, permission prompts) is fine when it's true and useful context; Wilbur
is never described as a Claude Code fork, rebrand, or affiliated product.

**Glyph:** `✻`

**Colours**

| Use | Value |
|---|---|
| CLI gradient (ANSI 256, dark→light) | `130 166 173 209 216 223` |
| Icon background gradient, dark stop | `#a8431c` |
| Icon background gradient, light stop | `#e8743b` |
| Icon face gradient, dark stop | `#f6c2ad` |
| Icon face gradient, light stop | `#ffe9df` |
| VS Code `galleryBanner.color` | `#a8431c` (matches the icon's dark stop) |

**Icon files**

- `vscode/media/icon.svg` — source (pig face, terracotta gradient, `✻`).
- `vscode/media/icon.png` — rendered Marketplace/extension-list icon.
- `vscode/media/wilbur.svg` — monochrome activity-bar mark, theme-tinted.

**Usage rules**

- One name everywhere: "Wilbur". Capitalize as a proper noun; lowercase
  `wilbur` only for the CLI command itself.
- Terracotta ramp + `✻` glyph are the only brand marks; don't introduce a
  second palette or mascot in new surfaces (docs, site cards, badges).
- The public mirror (`github.com/jsonholdings/wilbur`, once created) uses
  the same name, tagline and colours — no separate identity for the OSS
  presentation.
